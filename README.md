# Audioswipe

Слушай вслепую. Открывай ноунеймов. Собирай фиты.

Audioswipe — сервис для тех, кто ищет новую музыку без предубеждений, и для артистов, которые хотят честный фидбек и коллаборации.

## Как начать

1. Открой сайт и выбери **«Я Слушатель»** или **«Я Артист»**.
2. Зарегистрируйся или войди по **логину (email) и паролю**.
3. Можно переключаться между режимами слушателя и артиста в шапке — один аккаунт на оба кабинета.

## Для слушателей

**Радар** — настрой глубину (от андеграунда до чартов) и жанры, затем запусти прослушивание. Имена артистов скрыты, пока ты не решишь, что трек тебе зашёл.

- **Скип** — следующий трек.
- **Нравится** — короткий фидбек и раскрытие карточки артиста.
- **🚫** — скрыть артиста из ленты (нужен вход в аккаунт).

Понравившиеся находки сохраняются в **«Мои находки»**. Если артист открыт к коллабам — можно предложить фит.

## Для артистов

**Моя музыка** — загружай демо; другие слушатели увидят их в радаре «Локальные».

**Искать фит** — профиль для коллабораций: роль, софт, статус, референсы.

В кабинете артиста видна аналитика прослушиваний и отзывы от слушателей.

## Идея

Audioswipe убирает «узнавание по обложке и имени» — сначала звук, потом решение. Так проще находить новых артистов и собирать честную обратную связь.
